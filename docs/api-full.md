### MeshBuilder

Every vertex has a position, texture coordinates, a normal and a color. Without

```valk
let builder = raylib.MeshBuilder{}
builder.vertex(.{ x: 0, y: 0, z: 0 }, .{ x: 0, y: 0 }, .{ x: 0, y: 1, z: 0 }, raylib.WHITE)
builder.vertex(.{ x: 1, y: 0, z: 1 }, .{ x: 1, y: 1 }, .{ x: 0, y: 1, z: 0 }, raylib.WHITE)
builder.vertex(.{ x: 1, y: 0, z: 0 }, .{ x: 1, y: 0 }, .{ x: 0, y: 1, z: 0 }, raylib.WHITE)
```

#### normals

Whether vertices keep their normal. Turn it off for a shader that does not use
normals: the mesh gets none, and a third less memory.

#### build

Copies the vertices into a new `Mesh` and uploads it to the GPU, which needs an open
window. Pass `upload: false` to keep it on the CPU, e.g. for `get_mesh_bounding_box`.
Free it with `unload_mesh`, or through `unload_model` once a model owns it.

raylib keeps a copy of the vertices next to the one on the GPU. `keep_data: false`
frees it after the upload: the mesh still draws and unloads, but its vertices can no
longer be read, e.g. by `get_mesh_bounding_box`.

more than 65536 vertices.
